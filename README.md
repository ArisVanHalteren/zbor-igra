# Zbor Igra

A small Macedonian word game: flashcards to learn each unit, then match the words, finish the sentence and tap to write the sentence across 17 units. Mistakes are explained, any Macedonian word can be tapped for its meaning, tricky words get their own relaxed review, and a vocabulary page tracks what you know. Hearts, timers, combos, day streaks, levels, badges and a 60-second Blitz mode keep it fun.

It is a static web app with no build step. Open `index.html`, or install it on a phone from its GitHub Pages address (Safari → Share → Add to Home Screen). It works offline after the first visit, and progress is stored on the device.
