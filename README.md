# Zbor Igra

A small Macedonian word game: match pairs, pick meanings, finish and build sentences across 17 units, with hearts, timers, combos, levels, badges and a 60-second Blitz mode.

It is a static web app with no build step. Open `index.html`, or install it on a phone from its GitHub Pages address (Safari → Share → Add to Home Screen). It works offline after the first visit, and progress is stored on the device.
